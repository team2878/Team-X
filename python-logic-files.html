Part 1 · Boolean logic

5 lessons

01True and False

A boolean is a value that can only be one of two things.

Python's boolean type is called bool, and its only two values are True and False. They always start with a capital letter: true is just an undefined name and will raise a NameError.

Every if statement and while loop asks one question: is this condition True or False? That's why booleans are at the heart of every decision your program makes.

Fun fact: bool is a subclass of int. True == 1 and False == 0, so True + True gives 2.
is_raining = True
has_umbrella = False

print(type(is_raining))   # <class 'bool'>

if is_raining:
    print("Take a jacket!")

print(True + True)        # 2
print(isinstance(True, int))  # True

03Logical operators: and, or, not

Combine several conditions into one decision.

  • A and B is True only when both are True.
  • A or B is True when at least one is True.
  • not A flips the value.

Precedence: not runs first, then and, then or. So True or False and False is True or (False and False), which is True. Use parentheses when in doubt.

age = 20
has_ticket = True
is_banned = False

can_enter = age >= 18 and has_ticket and not is_banned
print(can_enter)   # True

weekend = True
holiday = False
print(weekend or holiday)   # True

04Truthy and falsy values

Any Python value can be used as a condition, not only True and False.

When a value sits in an if, Python quietly calls bool() on it. Only a short list of values count as falsy:

False, None, 0, 0.0, "", [], (), {}, set(), range(0)

Everything else is truthy, including "0", "False", " " and -1.

name = input("Your name: ")

if name:                 # same as: if name != ""
    print("Hello", name)
else:
    print("You didn't type anything")

items = []
if not items:
    print("The list is empty")

05Short-circuit evaluation

Python stops evaluating as soon as it knows the answer, and returns one of the actual operands.

  • and returns the first falsy value, or the last value if all are truthy.
  • or returns the first truthy value, or the last value if all are falsy.
  • The right side is never run if the left side already decides the result.
This is why x and x.strip() is safe even when x is None: the method call is never reached.
print(0 and 5)        # 0      (first falsy)
print(3 and 5)        # 5      (all truthy, last one)
print("" or "guest")  # guest  (first truthy)
print(None or 0)      # 0      (all falsy, last one)

# Default value pattern
username = ""
display = username or "Anonymous"
print(display)        # Anonymous

# Safe check: len() never runs on None
data = None
if data and len(data) > 0:
    print("has data")

f = open("notes.txt", "r", encoding="utf-8")

f.close()     # always close, or better, use "with" (lesson 09)
Pass encoding="utf-8" for text files. Without it Python uses your system default, which differs between Windows, Mac and Linux.

08Writing and appending

"w" starts fresh, "a" adds to the end.

write
with open("todo.txt", "w", encoding="utf-8") as f:
    f.write("Buy milk\n")
    f.write("Study Python\n")

# write() does NOT add a newline for you
lines = ["a\n", "b\n", "c\n"]
with open("abc.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
append
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("User logged in\n")

# print() can write to files too
with open("log.txt", "a", encoding="utf-8") as f:
    print("Another entry", file=f)
Opening an existing file with "w" wipes it the moment it opens, even if you never call write(). Use "a" to keep old content, or "x" to refuse to overwrite.

09The with statement and errors

Boolean logic and files meet here: check, then act safely.

with open(...) as f: closes the file automatically when the block ends, even if an error happens inside it. That's why it's the standard way to work with files.

To handle problems, wrap the code in try / except, or check first with os.path.exists(), which returns a boolean.

import os

path = "config.txt"
if os.path.exists(path) and os.path.getsize(path) > 0:
    print("Config found and not empty")
try:
    with open("data.txt", encoding="utf-8") as f:
        text = f.read()
except FileNotFoundError:
    print("File not found, creating it")
    with open("data.txt", "w", encoding="utf-8") as f:
        f.write("")
except PermissionError:
    print("No permission to read this file")
else:
    print("Read", len(text), "characters")
finally:
    print("Done")
